# KUDI-LINK

A static frontend prototype for a digital business passport experience built in plain HTML, CSS, and vanilla JavaScript.

## Features

- Landing page with premium fintech styling
- Dashboard overview with mock finances and revenue chart
- Business Passport details and timeline
- Transaction search, filtering, and modal details
- Insights cards and simple chart layout
- Connect account prototype flow
- Share passport page with QR-style visualization and copy-to-clipboard
- Settings and permission toggles using localStorage
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages deployment

A GitHub Actions workflow is included under `.github/workflows/deploy.yml` to publish the repository to GitHub Pages.
